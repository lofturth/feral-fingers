# Five-voice MIDI experiment

Run the dashboard bridge first, then install python-rtmidi and run router.py with a Python that has it. The router subscribes to http://127.0.0.1:8766/events and never opens the Feather serial port. Defaults: Minilab37 MIDI input, IAC Driver Bus 1 output. Override exact port names with --keyboard and --output. Chord player: http://127.0.0.1:8767/. Local JSON diagnostics: http://127.0.0.1:8767/status. Press Ctrl-C to stop; the router sends Note Off for any locked chord and CC1=0. SIGTERM also performs cleanup. Abrupt process termination or failure of the MIDI destination can prevent cleanup.

For macOS, enable the IAC Driver in Audio MIDI Setup. In Ableton Live's MIDI settings, enable Track for both IAC Driver Bus 1 and Minilab37 MIDI inputs. In Live Melody mode, set the four harmony tracks to MIDI From: IAC Driver Bus 1, channels 1–4 respectively. Set the melody track to All Ins / Ch. 5 to combine direct MiniLab channel 5 notes with IAC channel 5 CC1. Set Monitor to In (or Auto and arm the tracks). Disable or exclude other channel 5 input ports and duplicate MiniLab routes, and do not route MIDI back to the IAC bus. Use Live Melody Off for the original five-channel IAC setup and MiniLab chord input.

In Live Melody mode, the router closes the MiniLab input and sends four harmony notes on channels 1–4; the MiniLab sends melody directly to Live. Stop All Notes sends CC123 and CC120 to IAC channels 1–5, but cannot guarantee release of notes arriving via the separate MiniLab input. The router maps left thumb, index, middle, ring, and pinky from mux channels 3, 4, 5, 6, 7 to MIDI channels 1, 2, 3, 4, 5 respectively. The separate gravity dashboard retains its own display mapping.

Five distinct simultaneously held notes are sorted and locked to Thumb, Index, Middle, Ring, Pinky. The five Note Offs are sent only when all original keys have been released. Extra notes are ignored during a chord. Keyboard disconnection sends Note Offs. CC1 is max(0, estimated gravity Z), clamped to 1 and scaled to 0–127 and transmitted independently on channels 1–5. Missing/stale sensor data (>0.5 s) sends CC1=0 for the affected voice and resets that estimator; this closes expression but does not end a held MIDI note. Actual silence depends on how WiteL maps CC1. The existing dashboard's estimator is reused with the router's left-hand mapping; no firmware change is required.

Enter five distinct note names (C4 = MIDI 60), including sharps or flats if desired, then Play. Stop releases the active chord. A new Play releases any previous chord first. The typed player and MiniLab chord lock are exclusive: Play replaces a keyboard chord, and keyboard note events are ignored while a typed chord is held. Stopping a typed chord returns to keyboard mode. Disconnecting the keyboard releases a keyboard chord but does not interrupt a typed chord.
