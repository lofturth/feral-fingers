# Five-voice MIDI experiment

Run the dashboard bridge first, then install python-rtmidi and run router.py with a Python that has it. The router subscribes to http://127.0.0.1:8766/events and never opens the Feather serial port. Defaults: Minilab37 MIDI input, IAC Driver Bus 1 output. Override exact port names with --keyboard and --output. Chord player: http://127.0.0.1:8767/. Local JSON diagnostics: http://127.0.0.1:8767/status. Press Ctrl-C to stop; the router sends Note Off for any locked chord and CC1=0. SIGTERM also performs cleanup. Abrupt process termination or failure of the MIDI destination can prevent cleanup.

For macOS, open Audio MIDI Setup > Window > Show MIDI Studio > IAC Driver and enable Device is online; one bus suffices. In Live MIDI settings enable Track for that IAC input. Put a WiteL on each of five separate MIDI tracks. In each track select MIDI From: IAC Driver Bus 1 and select input channel 1, 2, 3, 4 or 5 respectively; set Monitor to In (or arm the track with Auto). Do not use All Channels or All Ins for these tracks, and do not route their output back into the IAC bus. Disable the MiniLab's direct Track input in Live or select only the IAC bus for these tracks to prevent doubled notes.

Five distinct simultaneously held notes are sorted and locked to Thumb, Index, Middle, Ring, Pinky. The five Note Offs are sent only when all original keys have been released. Extra notes are ignored during a chord. Keyboard disconnection sends Note Offs. CC1 is max(0, estimated gravity Z), clamped to 1 and scaled to 0–127 and transmitted independently on channels 1–5. Missing/stale sensor data (>0.5 s) sends CC1=0 for the affected voice and resets that estimator; this closes expression but does not end a held MIDI note. Actual silence depends on how WiteL maps CC1. The existing dashboard's estimator and mapping are reused; no firmware change is required.

Enter five distinct note names (C4 = MIDI 60), including sharps or flats if desired, then Play. Stop releases the active chord. A new Play releases any previous chord first. The typed player and MiniLab chord lock are exclusive: Play replaces a keyboard chord, and keyboard note events are ignored while a typed chord is held. Stopping a typed chord returns to keyboard mode. Disconnecting the keyboard releases a keyboard chord but does not interrupt a typed chord.
